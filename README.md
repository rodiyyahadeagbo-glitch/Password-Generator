# Password-Generator
A beginner-friendly Python password generator built with cybersecurity best practices in mind.
This project generates strong, random passwords using uppercase and lowercase letters, numbers, and symbols, with a minimum length of 8 characters.
It focuses on understanding password hygiene, randomness, and secure authentication principles.
This is the first stage of a continuous project and will be expanded with features like password validation, reuse checks, and file-based storage
